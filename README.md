# Encender Minecraft

Una pequeña interfaz para arrancar servidores de Minecraft rápidamente y con un estilo limpio y sencillo.

## Descripción

Esta página permite:

- Iniciar servidores de Minecraft con un solo clic.
- Ver el estado del arranque en tiempo real.
- Consultar la IP final cuando el servidor esté listo.
- Mantener una experiencia simple, clara y visualmente agradable.

## Servidores disponibles

- Mods
- Invierno

## Cómo usarlo

1. Abre `index.html` en tu navegador.
2. Elige el servidor que deseas iniciar.
3. Introduce la contraseña cuando se te pida.
4. Espera a que el servidor se prepare.
5. Cuando esté listo, se mostrará la dirección IP del servidor.

## Requisitos

- Un navegador moderno.
- Acceso al backend que expone los endpoints de arranque y estado.

## Archivos principales

- `index.html`: interfaz principal y lógica de arranque.
- `README.md`: documentación del proyecto.

## Nota

La aplicación está pensada para uso sencillo y rápido, y requiere que los endpoints de AWS o backend asociados estén funcionando correctamente.
